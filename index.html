Privacy Policy

Phrasebeat Language Player　隱私權政策

生效日期：2026 年 10 月 24 日 適用範圍：Android 版 App「Phrasebeat Language Player」

這是一個離線優先的個人影片語言學習工具：播放你自己裝置上的影片或 YouTube 影片、對照雙語字幕、 校正時間軸，也可以選用 AI 自動產生字幕。以下說明哪些資料會離開你的裝置、送到哪裡去，哪些完全不會。

資料速覽

留在裝置上

你選的影片、字幕檔、播放紀錄、shift time 校正、白板收藏、App 設定、你自己填的 API Key 全部存在裝置本機，開發者的伺服器完全看不到、也拿不到——因為根本沒有伺服器。

你主動觸發才會送出

按「自動翻譯」「搜尋」「用 Gemini 自動產生字幕」時 對應的文字、YouTube 連結或音訊片段會送到 Google 或 DeepL，詳見下方「第三方服務」與「Gemini 自動產生字幕」。

播放 YouTube 影片時

由 YouTube 官方嵌入播放器處理 套用 Google 自己的隱私權政策，這個 App 不會另外蒐集。

廣告

App 內有 Google AdMob 廣告（橫幅與插頁） AdMob 可能蒐集廣告 ID 等裝置資訊，詳見下方「廣告」。

沒有帳號

不需要註冊登入，開發者沒有自己的分析或追蹤工具 開發者不會知道你是誰、看了什麼影片、做了哪些字幕。

01

我們如何存取你的影片與字幕

App 透過 Android 內建的「Storage Access Framework」讀取檔案：你自己挑一個資料夾授權 （例如相簿裡的 Movies 資料夾），之後 App 只能在那個資料夾底下瀏覽、播放、讀寫字幕檔， 拿不到裝置上其他地方的任何檔案。這個授權可以隨時在 Android 系統設定裡收回。

影片本身、字幕內容、你做的每一筆時間軸校正、跳過/合併/編輯紀錄、白板收藏，全部只存在你的裝置上 （用 App 自己的私有儲存空間，跟影片檔案分開放），不會上傳、不會備份到任何雲端、 開發者也沒有管道讀取這些內容。你選擇「儲存到資料夾」時，App 會在你指定的資料夾裡寫入 YouTube 連結檔（.path）與字幕檔（.srt），這些檔案由你自己保管。

02

Gemini 自動產生字幕（選用）

如果你想讓沒有字幕的影片自動產生逐字稿，可以使用這個功能。它完全是選用的，而且使用的是 你自己向 Google 申請的 Gemini API Key：

  • API Key：只存在你裝置的 App 私有儲存空間，不會傳給開發者；只會在呼叫 Google 時當作憑證送給 Google。
  • YouTube 影片：App 把該影片的連結送給 Gemini API，由 Google 自己讀取影片內容並回傳逐字稿；影片不會經過開發者。
  • 你裝置上的影片或音檔：App 先在裝置上只取出「聲音」（不含畫面），壓縮成約 5 分鐘一段的短音訊， 在你於畫面上按下確認之後才送給 Gemini API；暫存的音訊片段用完就刪除。
  • 結果：產生的字幕存在你的裝置上，也可能存成影片旁邊的 .srt 檔。

送給 Gemini API 的內容會依照 Google 對 Gemini API 的條款處理。使用免費額度時，Google 可能會把送出的內容 用來改進它的產品，所以請不要對私人錄音、機密內容使用這個功能；付費方案的處理方式不同，請以 Google 的條款為準。

03

第三方服務

以下功能都是選用的，只有你主動操作才會把資料送出裝置：

功能觸發時機送出什麼送到哪裡
Gemini 自動產生字幕 在播放畫面設定裡選「用 Gemini 自動產生字幕」 YouTube 連結，或本機影片取出的音訊片段（見上方第 02 節） Google（Gemini API）
自動翻譯字幕 設定頁選了翻譯服務、在播放畫面按下「自動翻譯」 還沒有母語翻譯的字幕文字 Google 翻譯，或你自己填 API Key 的 DeepL
查字典 反白選字後按「搜尋」 你選取的文字 Google 搜尋（App 內建瀏覽器開啟）
YouTube 影片播放與資訊 貼上或分享 YouTube 連結、開啟 YouTube 影片 影片編號（用來取得標題與縮圖）；播放本身由 YouTube 官方嵌入播放器自行處理 YouTube／Google
字體下載 App 啟動、套用主題時 不含個人資料，僅下載字型檔本身 Google Fonts
廣告 使用 App 時顯示廣告 見下方第 04 節 Google AdMob

這些服務各自的資料處理方式，請參考它們自己公開的政策：

  • Google 隱私權政策（涵蓋 Google 翻譯、Google 搜尋、YouTube、Google Fonts）
  • Gemini API 附加服務條款（Gemini 自動產生字幕）
  • Google 如何使用使用其服務的網站或應用程式中的資訊（AdMob 廣告）
  • DeepL 隱私權政策（只有你自己設定 DeepL API Key 才會用到）
04

廣告

這個 App 內有 Google AdMob 提供的廣告：在畫面下方有橫幅廣告；累計使用滿 60 分鐘後， 你按下播放相關的控制項時，會出現一次插頁廣告，看完之後重新計時。

  • AdMob 可能蒐集的資料：廣告 ID、IP 位址、裝置與系統資訊、廣告互動與 App 使用相關資料，用來顯示廣告、衡量成效與防止濫用。這些資料由 Google 依其政策處理，開發者不會直接收到你的個人資料。
  • 個人化廣告與同意：在需要徵求同意的地區（例如歐洲經濟區、英國），會先顯示 Google 的同意表單，你可以選擇是否同意個人化廣告。你也可以隨時到 Android「設定 → Google → 廣告」重設廣告 ID 或停用個人化廣告。
  • 使用時間計時：為了決定何時顯示插頁廣告，App 會在裝置本機累計「App 在前景的使用時間」，只存在裝置上，不會上傳；待機或切到其他 App 的時間不計入。
05

藍牙遙控與媒體按鍵

App 可以接收藍牙耳機、遙控器的播放、停止、重播、音量等按鍵來控制播放。這只是接收「按了哪一顆鍵」， 不會讀取或記錄藍牙裝置的名稱、位址或其他資訊；你自己指定的按鍵對應只存在裝置本機。

06

分享功能

播放畫面的「分享」按鈕，是叫出 Android 系統原生的分享選單，把一段文字（跟本機影片會 額外剪出的一小段 mp3）交給你自己選的其他 App（例如 Anki、訊息、雲端硬碟）。 這個過程完全由你決定要分享給誰，App 本身不會把這些內容送到任何地方。 同樣地，你從 YouTube 等 App「分享」連結給這個 App，只是讓 App 讀到那個連結，不會另外保存或回傳。

07

權限說明

App 本身只會要求「網路連線」這一個權限：

  • 網路連線：翻譯、查字典、YouTube 播放、Gemini 自動字幕、下載字型、顯示廣告都需要連上網路才能運作。

另外，App 內建的元件會帶入下列權限，用途如下：

  • 網路狀態、廣告 ID、Android 廣告服務（廣告 ID、成效歸因、興趣主題）：Google AdMob 廣告元件用來顯示與衡量廣告，詳見第 04 節。
  • 保持喚醒：影片播放元件用來避免播放中途被系統休眠打斷。

App 不會要求裝置的完整檔案存取權限，也不會要求相機、麥克風、聯絡人、定位、藍牙連線等權限。

08

兒童隱私

這個 App 不是針對 13 歲以下兒童設計，也不會刻意蒐集兒童的個人資料；顯示的廣告也是一般受眾的廣告。

09

刪除你的資料

因為所有資料都只存在你的裝置上，解除安裝這個 App，或是在 Android 系統設定裡清除 App 資料，就會把所有播放紀錄、字幕校正、白板收藏、設定（包含你填的 API Key）完全刪除， 不需要另外聯絡開發者。你自己存到資料夾裡的 .path、.srt 檔案，請自行刪除。 已經送到 Google、DeepL 的內容，請依各服務自己的方式處理。
